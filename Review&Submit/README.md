# Review & Submit

Google Apps Script project bound to the [ClinGen ClinVar Curation Review & Submit](https://docs.google.com/spreadsheets/d/1ZPADw8DPh5iZxqsNDVM24T1p4AzmStqrcpOWdtHOUp8/edit?gid=0#gid=0) Google Sheet.

This sheet and its scripts manage the review, batch assignment, and submission of ClinVar curation annotations created by the [ClinVar Curation Chrome Extension](../scvc/). After curators capture annotations with the extension, those annotations flow into this sheet for review, approval, and eventual submission to ClinVar as newline-delimited JSON files.

## Workflow Overview

1. **Refresh** -- Pull the latest annotations from BigQuery (`clinvar_curator.cvc_annotations`) into the sheet via a connected data source table.
2. **Review** -- Reviewers examine each annotation on the "Review & Submit" sheet and set a status: OK, Fixed, Archive, or Question. Some annotations are auto-approved based on rules (e.g., "no change" actions, annotations from authorized reviewers, deleted SCVs).
3. **Assign** -- Approved annotations (status = OK, action = "flagging candidate" or "remove flagged submission") are assigned to the next batch using checkbox selection.
4. **Generate** -- A submission file is generated by querying BigQuery for all annotations in the batch, producing a newline-delimited JSON file saved to the [ClinVar Submissions](https://drive.google.com/drive/folders/1w_hncksAMGAmVIVVDJVD3M0fGVj4KL80) shared Google Drive folder.
5. **Finalize** -- The batch is finalized: a draft email is created with the submission file attached, review and submission records are persisted to BigQuery standard tables, the sheet is cleared, and the batch ID is incremented for the next cycle.

## Files

| File | Description |
|---|---|
| **Code.js** | Core sheet functions: `onEdit` handler for tracking review timestamps, `refresh` to sync annotations from BigQuery, `appendNewToReviews` to populate the Review & Submit sheet with auto-review logic, and utility functions (date formatting, checkbox clearing, transpose). |
| **Generate.js** | Batch file generation and finalization: `generate` queries BigQuery and writes NDJSON submission files to Google Drive, `finalizeBatch` orchestrates the full finalization workflow (generate, draft email, persist to BigQuery, clear sheet, increment batch ID), `createDraftEmail` drafts a Gmail message with the file attached. |
| **ReviewSubmit.js** | Batch assignment management: `assignToNextBatch` and `unassignFromNextBatch` handle checkbox-driven batch assignment of reviewed annotations, with validation dialogues to confirm actions and guard against invalid selections. Also defines the action and review status constants used across scripts. |
| **SUBMISSION_FILE_SPEC.md** | Specification for the generated submission file format, including field definitions, reason values by action, row-level semantics, batch lifecycle, and FAQ. |
| **appsscript.json** | Apps Script project manifest. Configures advanced services: BigQuery v2, Google Sheets v4, Drive v2, and Gmail v1. |
| **.clasp.json** | [clasp](https://github.com/google/clasp) configuration linking this local directory to the bound Apps Script project for CLI-based deployment. |

## Infrastructure

- **Google Cloud Project**: `clingen-dev`
- **BigQuery Dataset**: `clinvar_curator`
- **Key BigQuery Tables**:
  - `cvc_annotations` -- Source annotations (table-valued function, parameterized)
  - `cvc_clinvar_submissions_sheet` / `cvc_clinvar_submissions` -- External (sheet-linked) and standard submission tables
  - `cvc_clinvar_reviews_sheet` / `cvc_clinvar_reviews` -- External and standard review tables
  - `cvc_clinvar_batches` -- Finalized batch metadata
- **Submission Files**: Saved to [ClinVar Submissions](https://drive.google.com/drive/folders/1w_hncksAMGAmVIVVDJVD3M0fGVj4KL80) shared Drive folder

## Named Ranges

The sheet uses several named ranges referenced by the scripts:

| Named Range | Purpose |
|---|---|
| `next_batch_id` | The batch ID for the current/next submission cycle |
| `lastRefreshExecutedAt` | Timestamp of the last data refresh |
| `reviewers` | List of curators whose annotations are auto-approved |
| `submissionRecipients` | Email recipients for submission draft emails |
| `submissionCcRecipients` | CC recipients for submission draft emails |
| `mostRecentSubmittedBatchGeneration` | Datetime of the most recently finalized batch |

## Development

This project uses [clasp](https://github.com/google/clasp) for local development and deployment to Google Apps Script.

```bash
# Push local changes to the bound Apps Script project
clasp push

# Pull remote changes to local
clasp pull

# Open the Apps Script editor in browser
clasp open
```
