Column guide — what the flags mean
SCV rev status
ClinVar's review status (star rating) for the SCV.
latest anno
This is the latest CvC annotation for the SCV; blank means a newer annotation supersedes it.
outdated vcv
A newer VCV (variant record) version exists than when the annotation was made.
outdated scv
A newer SCV (submission) version exists, or the SCV moved to a different variant.
moved
The SCV moved to a different ClinVar variation since the annotation.
deleted
The SCV was deleted from ClinVar on or before the annotation's release.
deleted rel date
The ClinVar release date on which the SCV was deleted.
latest scv ver
The current latest version number of the SCV.
latest scv classif
The SCV's current classification — compare with the classification at annotation time.
prior same ver
A prior CvC annotation exists for this exact SCV version.
prior submitted
A prior CvC annotation for this SCV was submitted in a batch.
Auto
The auto-review suggested status (hover the cell for the reasoning).
Status
Your CvC review status — OK / Fixed / Archive / Question, or (none).
Batch
Whether the row is assigned to the next batch, or why it isn't eligible (hover).
